## Abstract 
In November 2025, the first global H5N5 infection was reported in a person in Washington State. Previously, these viruses had only been detected in seabirds and shorebirds near the Atlantic Ocean, suggesting potentially distinct ecology from dominant H5N1 strains. Using 354 global H5N5 genomes, we show that H5N5 viruses have been carried by high latitude seabirds and shorebirds across the Atlantic at least 9 times, with introductions more frequent in the fall and spring. We reconstruct a plausible path of cross-continental movement via Arctic or sub-Arctic regions, followed by a year of cryptic circulation prior to human spillover. These data show that H5N5 viruses have undergone far more intercontinental movements than previously recognized, and exhibit host and geographic patterns that are fundamentally distinct from dominant H5N1 lineages. The distinct host ecology, geography, and movement, paired with the capacity to infect a person, suggest that enhanced surveillance may be warranted.

## Overview
This repo contains all of the code used to perform the analyses of HPAI H5N5 described in this paper. Sequence data used in this analysis were sourced from GISAID, GenBank, or were directly provided by the team at Tufts University. The corresponding acknowledgements table for GISAID sequences can be found in the `alignments` folder.

## System requirements and installation

Bayesian phylodynamic analyses were performed using BEAST X v10.5 (https://beast.community). We performed analyses using the PARCC HPC cluster at UPenn.  

XML files for BEAST analysis can be run using standard command line interface or BEAST GUI with input files, runtimes vary depending on analysis.
